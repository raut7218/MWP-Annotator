Progress overview

Import workbook

Load a sheet of generated problems straight into the database. The file is parsed and summarised first — nothing is written until you confirm. Re-importing the same sheet refreshes the problem text and never touches annotations already saved.

Export annotated data

Downloads an .xlsx with the problem, its learning objective, the model that generated it, and one row per annotator with their flags, comments and review status.

Delete imported data

Removes the imported problems for one model/language and every annotation saved against them. Use this to clear a sheet that was imported wrongly; it cannot be undone.
